# Husk

Java 25 template for multiversion Spigot, Paper, Folia, Fabric, Forge, and NeoForge projects using VolmLib.

[Build and customize Husk](https://github.com/VolmitSoftware/docs/blob/master/husk.md)

`./gradlew build` produces one Bukkit jar and nine mod jars for Minecraft 26.1.2, 26.2, and 26.3 in `build/distributions/`.
