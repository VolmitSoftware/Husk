# Husk

Template for multiversion Spigot, Paper, Folia, Fabric, Forge, and NeoForge projects using VolmLib, built with JDK 25.

[Build and customize Husk](https://github.com/VolmitSoftware/docs/blob/master/husk.md)

`./gradlew build` produces one Bukkit jar and fourteen mod jars for Minecraft 1.20.1, 1.21.1, 26.1.2, 26.2, and 26.3 in `build/distributions/`.
